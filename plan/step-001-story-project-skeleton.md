# Step 001 — Story: Project skeleton

**Type:** Story · **Slice:** Foundation · **Depends on:** none

## Goal

As the developer, I can run the agent package with uv and type-check it, so every later
step has a place to land.

## Context

- [AGENTS.md](../AGENTS.md#tech-stack): Python 3.14, uv, the libraries.
- [containers.md](../docs/containers.md#decisions): one uv project for both images.

## Files

| File | Change |
| --- | --- |
| `pyproject.toml` | New. Project `email-agent`, Python 3.14, `src` layout. Runtime dependencies: `pydantic-ai-slim[anthropic,openai]`, `google-api-python-client`, `google-auth-oauthlib`. Dev group: `pyright`. Pyright set to strict on `src`. |
| `uv.lock` | Generated by `uv lock`. Never hand-edited. |
| `.python-version` | New. `3.14`. |
| `src/email_agent/__init__.py` | New, empty. Boilerplate. |
| `src/email_agent/__main__.py` | New. Prints one startup line and exits 0. |

## What to build

- A package `email_agent` under `src/`, runnable with `python -m email_agent`.
- The startup line names the agent and its version from package metadata.
- No logic yet. Later steps fill `__main__.py` with the startup order.

## Acceptance criteria

- [ ] `uv sync` installs without errors.
- [ ] `uv run python -m email_agent` prints the startup line.
- [ ] `uv run pyright` reports no errors.

## Out of scope

- Config, Google APIs, containers.
- The `wrapper` dependency group. Step 007 adds it.
