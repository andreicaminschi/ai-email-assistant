# Step 019 — Story: Email templates

**Type:** Story · **Slice:** Slice 3 · **Depends on:** 011

## Goal

As the developer, every outgoing email comes from one fixed template filled by code, so
the LLM never writes outgoing text and a missing value can't go out half-filled.

## Context

- [email-templates.md](../docs/email-templates.md): every template, placeholder and rule.

## Files

| File | Change |
| --- | --- |
| `src/email_agent/templates.py` | New. Loads a template by name and fills its placeholders from a mapping. A missing value raises before anything is saved. Handles the `[urgent: text]` parts and the urgent subject of the two approval templates. Appends nothing, since each file already ends with the disclaimer. Also builds `{quoted_text}` and `{slot}` from typed values. |
| `src/email_agent/templates/*.txt` | New. One plain-text file per template in the doc, copied word for word. Boilerplate. |

## What to build

- Template names are an enum, so a typo fails the type-check.
- Each template carries its subject: `Re: {original_subject}` for replies to the sender,
  its own subject for the two approvals.
- `{slot}` renders like `Thu 26 Nov 10:00–10:30`.
- `{quoted_text}` prefixes each line with `> ` and cuts at 1000 characters.
- `{sender_name}` falls back to the address.

## Acceptance criteria

- [ ] In `uv run python`, rendering the sales decline for Jane ends with `-- ` and
      `Generated by an LLM.` on the last two lines.
- [ ] Rendering the task approval with urgent off gives the subject `Approval needed:
      PTO` and the first line `Jane is asking for your approval. Reply yes or no.`. With
      urgent on, the subject starts `Urgent approval needed:` and the line adds `, and
      it's flagged urgent`.
- [ ] Leaving out `{slot}` in the meeting approval raises an error naming it.
- [ ] `uv run pyright` is clean.

## Out of scope

- Sending. Step 020 does that.
