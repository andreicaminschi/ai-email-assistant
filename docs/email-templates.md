# Email templates

Every email the agent sends comes from a fixed template. Code fills the placeholders, and
the LLM never writes outgoing text. When each email is sent is covered in
[approval.md](approval.md) and [classify-tree.md](classify-tree.md).

## Decisions

| Topic | Decision |
| --- | --- |
| Text | Fixed. Code fills `{placeholder}` values and changes nothing else. |
| Missing value | A placeholder without a value fails the render, before `SENDING` is saved. Nothing half-filled goes out. |
| Urgent text | A part written `[urgent: text]` keeps `text` when the urgent flag is set. Otherwise it's dropped. Only the two approval templates have one. |
| Format | Plain text. No HTML. |
| Disclaimer | Every body ends with the signature delimiter `-- ` and the line `Generated by an LLM.` |
| Replies to the sender | `Subject: Re: {original_subject}`, `In-Reply-To` and `References` set to the sender's `Message-ID`, and the API `threadId` set to T. |
| Forwards to the manager | The template's own subject, no `In-Reply-To`, no `threadId`, so Gmail starts a new thread F. Details in [approval.md](approval.md#the-forward). |
| Times | Everyone shares one time zone, so times carry no zone. |
| Sends | Every send uses the `SENDING` / `SENT` pattern from [retrieve-classify.md](retrieve-classify.md#sending-without-duplicates). |

## Running example

Jane (jane@acme.com) writes "Can we meet Thu 26 Nov 2026?" with the subject
`Quick sync`.

## Placeholders

| Placeholder | Holds | Example |
| --- | --- | --- |
| `{original_subject}` | The original subject, without `Re:` | `Quick sync` |
| `{sender_name}` | The display name from `From`, or the address when there's none | `Jane` |
| `{sender_email}` | The address from `From` | `jane@acme.com` |
| `{quoted_text}` | The sender's text, each line prefixed with `> `, cut at 1000 characters | `> Can we meet Thu 26 Nov 2026?` |
| `{slot}` | The meeting's start and end | `Thu 26 Nov 10:00–10:30` |

## Templates

| Template | To | Sent when |
| --- | --- | --- |
| [Sales decline](#sales-decline) | Sender | `SALES_OUTREACH`, unless `SEND_SALES_DECLINE=false` |
| [Approval: task](#approval-task) | Manager | Every `TASK` |
| [Approval: meeting](#approval-meeting) | Manager | A `MEETING_REQUEST` with a date |
| [Ask for a date and time](#ask-for-a-date-and-time) | Sender | A `MEETING_REQUEST` without a date |
| [Task approved](#task-approved) | Sender | The manager said yes to a task |
| [Task rejected](#task-rejected) | Sender | The manager said no to a task |
| [Meeting declined](#meeting-declined) | Sender | The manager said no to a meeting |

A yes to a meeting sends no template. Google emails the sender the invite.

### Sales decline

```text
Hi {sender_name},

Thanks for reaching out. We're not looking for this right now, so we'll pass.

Best regards

-- 
Generated by an LLM.
```

### Approval: task

Subject: `Approval needed: {original_subject}`, or `Urgent approval needed:
{original_subject}` when the urgent flag is set.

```text
{sender_name} is asking for your approval[urgent: , and it's flagged urgent]. Reply yes or no.

From: {sender_name} <{sender_email}>

{quoted_text}

-- 
Generated by an LLM.
```

### Approval: meeting

Subject: `Meeting request: {original_subject}`, or `Urgent meeting request:
{original_subject}` when the urgent flag is set.

```text
{sender_name} wants to meet on {slot}[urgent: , and it's flagged urgent]. Reply yes to book it or no to decline.

From: {sender_name} <{sender_email}>

{quoted_text}

-- 
Generated by an LLM.
```

### Ask for a date and time

```text
Hi {sender_name},

Thanks for reaching out. Could you send a specific date and time for the meeting, for example 26 Nov at 14:00?

Best regards

-- 
Generated by an LLM.
```

### Task approved

```text
Hi {sender_name},

Your request was approved.

Best regards

-- 
Generated by an LLM.
```

### Task rejected

```text
Hi {sender_name},

Your request was not approved.

Best regards

-- 
Generated by an LLM.
```

### Meeting declined

```text
Hi {sender_name},

Thanks for the invitation. Unfortunately we can't make {slot}.

Best regards

-- 
Generated by an LLM.
```
